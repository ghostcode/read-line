# Read-Line

在网页上显示一条跟随鼠标移动的阅读辅助线，帮助锁定当前阅读行，减少视觉疲劳。

![版本](https://img.shields.io/badge/version-0.0.1-green) ![Manifest](https://img.shields.io/badge/manifest-V3-blue)

---

## 功能特性

- **阅读辅助线** — 一条横向线跟随鼠标移动，精准锁定当前阅读位置
- **三种线型** — 实线 / 虚线 / 波浪线，按需切换
- **10 种颜色** — 内置 10 种颜色可选，支持亮色和暗色页面
- **线宽可调** — 1px ~ 6px，自由调整
- **快捷键切换** — `Ctrl + Shift + L` 快速显示/隐藏
- **黑白名单双模式** — 黑名单模式（默认显示，名单内不显示）/ 白名单模式（默认不显示，名单内才显示）
- **设置同步** — 通过 `chrome.storage.sync` 跨设备同步设置

## 安装

### 方式一：加载已解压的扩展（开发版）

1. 下载或克隆本仓库
2. 打开 Chrome，进入 `chrome://extensions/`
3. 开启右上角「**开发者模式**」
4. 点击「**加载已解压的扩展程序**」
5. 选择本项目的根目录

### 方式二：从 Chrome 应用商店安装

[应用商店](https://chromewebstore.google.com/detail/read-line/hnijpkiijmkiimdfdkciklmbcbokhpia)

## 使用说明

安装后，打开任意网页即可看到绿色阅读线跟随鼠标移动。

点击浏览器工具栏中的 Read-Line 图标，打开设置弹窗：

| 设置项 | 说明 |
|--------|------|
| 启用阅读线 | 总开关，关闭后所有网站均不显示 |
| 线条颜色 | 点击色块切换颜色，实时生效 |
| 线条类型 | 实线 / 虚线 / 波浪线，点击切换 |
| 线宽 | 拖动滑块调整线条粗细（1~6px）|
| 过滤模式 | 黑名单模式 / 白名单模式，点击切换 |
| 禁止/允许此网站显示阅读线 | 将当前网站加入/移出当前模式的名单 |

### 黑白名单模式

| 模式 | 行为 | 名单内的网站 |
|------|------|-------------|
| **黑名单模式**（默认） | 默认所有网站显示阅读线 | 不显示 |
| **白名单模式** | 默认所有网站不显示阅读线 | 显示 |

- 切换模式后，名单区域标题和按钮文案会自动更新
- 两个名单独立存储，切换模式不会丢失另一个名单的数据

### 键盘快捷键

| 快捷键（Windows / Linux） | 快捷键（macOS） | 功能 |
|--------|--------|------|
| `Ctrl + Shift + L` | `⌘ + Shift + L` | 切换当前标签页的阅读线显示/隐藏 |

**说明：**
- 快捷键在**网页有焦点时**即可生效，无需打开设置弹窗
- 在被名单过滤的网站（黑名单内或白名单外），快捷键无效
- 可在 `chrome://extensions/shortcuts` 中自定义或修改快捷键

**如何自定义快捷键：**
1. 在 Chrome 地址栏输入 `chrome://extensions/shortcuts` 并回车
2. 找到「Read-Line」扩展
3. 点击「设置快捷键」，按下你想要的组合键
4. 设置即时生效，无需重新加载扩展

## 技术实现

- **Manifest V3** — 使用最新扩展规范，无后台页面（background.js 已移除）
- **纯原生 JS** — 无任何依赖、无构建工具，直接加载
- **SVG 渲染** — 阅读线使用 SVG 绘制，支持曲线（波浪线）
- **RAF 节流** — 用 `requestAnimationFrame` 节流 mousemove，性能最优
- **GPU 加速** — 用 `transform: translateY()` 代替 `top`，避免重排
- **最小权限** — 仅申请 `storage` 权限，不读取浏览历史

## 已知问题

- `chrome://` 内部页面和扩展页面无法注入 content script，在这些页面打开 popup 会显示「当前页面不支持」
- 页面未完全加载时打开 popup，可能暂时无法识别当前网站（关闭 popup 重新打开即可）
